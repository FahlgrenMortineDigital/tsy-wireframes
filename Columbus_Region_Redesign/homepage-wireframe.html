2 Header + Main Navigation Shrinks on scroll WCAG 2.2 AA
Header + Nav — c2/c3/c4 · D1 · Heavy leverage (8–10 hrs)
  • Build: port Knox's Alpine.js mega-menu (desktop) / accordion drawer (mobile) and reskin. Logo is a Statamic Global asset.
  • Nav source: 7 top-level sections with dropdown panels; sub-links driven by a Statamic Navigation structure (not hard-coded). Sub-link dots = each page's content status.
  • Behavior: sticky header, shrinks on scroll. Disclosure pattern (see WCAG note below).
  • Search (s14): icon in the nav bar opens a full-width slide-down drawer (JobsOhio pattern). Statamic Search (Algolia or local) indexing Pages, News, Press Releases, Counties, Employers.
  • Popular Searches: data-driven — derived from GA top-traffic pages + SEMrush keyword-gap volume + the site-consultant conversion funnel (Site Selection, Incentives, Top Employers, Real Estate, Semiconductors/Intel, Cost of Doing Business, Success Stories, Workforce). Editable as a Statamic Global.
  • Responsive: desktop nav collapses to hamburger drawer at ≤1080px; search drawer form stacks at ≤760px.
Navigation — WCAG 2.2 AA build requirements
  • 2.1.1 Keyboard (A): each top-level item is a <button aria-expanded> — opens/closes on click, Enter or Space.
  • 1.4.13 Content on Hover or Focus (AA): the panel is Dismissible (Esc closes & returns focus to the trigger), Hoverable (no gap between trigger and panel), and Persistent.
  • 4.1.2 Name, Role, Value (A): aria-expanded reflects open state; aria-controls points to the panel id.
  • 2.4.7 Focus Visible (AA): visible focus ring on the trigger and every sub-link.
  • 2.4.11 Focus Not Obscured (AA — new in 2.2): the sticky header must not hide a focused link (apply scroll-margin-top).
  • 2.5.8 Target Size Minimum (AA — new in 2.2): triggers & links are ≥ 24×24 px.
  • Search drawer: toggle is a <button aria-expanded aria-controls>; focus moves to the field on open, Esc closes and returns focus to the toggle, backdrop click dismisses.
Hover still opens the menu as a convenience — keyboard, Esc, and click-outside are all supported. Toggle this note via “Accessibility (WCAG)” in Wireframe Controls.
